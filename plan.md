## The idea is:

We will code everything in english
We will use one repository for frontend and backend
We will use docker compose for it

### Stack:
#### backend
    - python
    - fastapi
    - numpy
    - preprocessed data

#### frontend
    - connect to backend api
    - reactjs
    - vite
    - leaflet

The project is called terranova because I think it sounds cool
We will use cellular automata and it will hopefully work and look visually cool.
